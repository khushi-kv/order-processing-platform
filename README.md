# Event-Driven Order Processing Platform

A production-grade **Spring Boot 3 Microservices Platform** featuring **Apache Kafka** event streaming, **Redis** caching, **Spring Cloud Gateway**, and **Resilience4j** circuit breakers.

> Full README with architecture diagrams, setup instructions, and API documentation coming soon.

## Tech Stack

- **Java 17** / **Spring Boot 3.3.2**
- **Apache Kafka** (KRaft mode) — Asynchronous event-driven communication
- **Redis** — Distributed caching (Cache-Aside pattern)
- **Spring Cloud Gateway** — API routing & reverse proxy
- **Resilience4j** — Circuit breakers & fault tolerance
- **PostgreSQL** — Persistent storage (database-per-service)
- **Docker Compose** — Infrastructure orchestration
